# Pen Detector

A YOLOv8n model that finds pens in a webcam video. It shows a box and a confidence score.

- 124 labeled images: 99 for training and 25 for validation.
- Live FPS, a confidence slider, and smoother boxes.
- Detection alerts, video recording, and CSV test logs.

To run the project, read [START.md](START.md). See [RESULTS.md](RESULTS.md) for results and limits.

Model: [Ultralytics YOLOv8n](https://docs.ultralytics.com/models/yolov8/) (AGPL-3.0).
